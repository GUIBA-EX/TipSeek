# 3. Profiling

[English version](profiling_EN.md) · [项目总览](../README.md) · [命令行指南](../manual/ZH_CN/command_line.md) · [输出说明](../manual/ZH_CN/output.md)

Profiling 默认从 WGS 或 metagenome reads 中免组装恢复 marker 的参考序列级证据，不估计生物量比例。可选的 `--profile-copy-mode host|symbiont` 增加 ITS2 多拷贝组装及 reads 支持检查。

## 流程

```text
TipSeek k-mer 招募 → Themisto 伪比对 → 参考序列级证据
```

未启用多拷贝模式时，不会运行 `refilter`、`assemble`、`combine` 或 `tree`。招募与 Themisto 统一使用 k=21。

## 输入

始终需要：

- 通过 `-r` 提供一个 `.fa` 或 `.fasta` marker 参考库。
- 含 WGS 或 metagenome reads 的样本表。
- `themisto`，放在当前环境的 `PATH`。

可选：

- `--profile-group-map` 两列 TSV：`reference_id<TAB>group`。它是参考序列级结果中的可选注释列。
- `--profile-decoy`：可能的非目标序列 FASTA。

reference ID 是 FASTA 标题第一个空白前字段。若提供 map，它必须恰好覆盖每条参考；重复行仅在 group 相同时允许。

## 运行与 cache

```bash
cli/tipseek profiling \
  -f samples.tsv -r marker_reference.fasta \
  -o output -p 8
```

只有需要给参考序列附加类别时，才加 `--profile-group-map marker_groups.tsv`。Themisto index 使用内容寻址 cache。用通用参数 `--reference-cache-dir` 在多次运行间共享；需要重建时使用新的缓存目录。直接调用 `marker_profile` 时，若改了参考、group map 或 decoy，应换用新 cache 或加 `--force-rebuild`。

profiling 专用参数只保留 `--profile-copy-mode`、`--profile-group-map` 和 `--profile-decoy`。招募、组装及索引统一使用 k=21，伪比对阈值 0.8、有效 k-mer 比例 0.5、索引内存 2 GB，均沿用已验证的默认值。索引内存是每个并发构建任务的设置，并非进程内存硬上限；用 `-p` 控制并发样本数。旧版的 profiling 调参、程序路径和缓存参数会明确报错，请移除并按需改用 `PATH`、`--reference-cache-dir`；不再读取 `GM2_THEMISTO`。实验性非默认伪比对可直接调用 `marker_profile`，其结果不等同于这里验证过的集成默认流程。

参数精简前后使用同一批三个 WGS 样本、两种模式进行对照，见[验证方法与结果](development/profiling-parameter-validation.md)。共享缓存键不依赖输出目录，参考输入变化时会生成新索引。

## 输出与解释

每个样本写入 `marker_profile/`。

### 主结果：`marker_reference_support.tsv`

每条命中的参考序列一行：

- `hit_queries`：与该参考相容的 query 数。
- `fractional_queries`：共享 query 的分数化支持；一条 query 有 N 个候选时，每个候选得 `1/N`，不会被重复计 N 次。
- `singleton_queries`：只与该参考相容的 query 数。
- `ambiguity_status`：`has_singleton_support` 或 `shared_only`。

它表示“与某参考序列相容”的证据，不代表该参考必然唯一存在，也不等于生物量丰度。

`marker_qc.tsv` 记录伪比对及运行参数。索引缓存内的 `marker_reference_metadata.tsv` 记录 Themisto color 到参考序列及可选 group 注释的映射。

## QC 与校准

解释结果前，应检查伪比对 query 数、各参考的分数化和单例支持，以及 decoy 参考的证据。应以匹配 marker 与测序深度的阴性对照、混合样和 downsampling 评估参考库与固定的伪比对默认值。跨样本比较时，固定参考库、可选注释 map、k-mer、阈值与 decoy 策略。

参见[Filter](filter_ZH.md)、[输出说明](../manual/ZH_CN/output.md)和[命令行指南](../manual/ZH_CN/command_line.md)。

## ITS2 多拷贝恢复

`--profile-copy-mode host|symbiont` 在现有 profiling 流程中增加 ITS2 图组装。两种模式共用证据检查：通过 `-r` 指定目标参考，通过 `--profile-decoy` 提供竞争或非目标参考。模式记录预期的生物学解释，本身不证明序列来源。不指定此参数时，继续使用不组装的 profiling。

多拷贝模式联合招募目标和干扰参考的 reads，保留双端关系及共享参考匹配，并关闭丰度降采样；用户显式设置的输入 reads 上限仍有效。参考用于招募、提供图种子和范围注释，不补入样本序列。不同候选序列分别保留。支持检查使用完整重叠、保守的碱基质量容忍、配对方向和变异位点间的连接证据。测序错误容忍及 ITS 生物学边界仍需进一步验证；`READ_SUPPORTED` 表示候选有 reads 证据，不代表全部基因组拷贝或完整 ITS 区域均已恢复。

每个样本的 `marker_profile/its2_candidates.fasta` 保留接纳及未解决的候选；`marker_profile/its2_candidates.tsv` 按稳定 ID 汇总覆盖、分相/接纳状态、拒绝原因、模式及独立的来源注释。`PARTIAL` 表示 reads 覆盖不足或未覆盖完整参考范围，`UNPHASED` 表示缺少位点连接证据或无法排除竞争路径。未解决候选的 EM 估计为 `NA`，不能解释为细胞丰度。

来源状态相对于所提供的参考库，包括 `target_only`、`decoy_only`、`ambiguous_source`、`unclassified`、`target_match_no_decoy`。reads 支持充分不能消除来源冲突；未提供干扰参考时的匹配也不证明排除了其他来源。图和未接纳候选保留供检查。本恢复模式已完成下述三个真实 WGS 样本的初步验证，尚未证明能找回全部低频拷贝。

当组装序列与目标参考的比对一致性至少为 80% 时，ITS2 恢复会先截取对应的样本区间（包括部分范围），再重新计算 reads 支持。末端替换使用实际样本碱基评估，样本插入保留，部分覆盖不补齐。报告增加参考相对边界和比对一致性；`its2_reference_spans.fasta` 保存方向统一的样本比对区间，也包括部分或未解决候选。这些注释描述所提供的标记参考范围，不证明完整基因组 rDNA 拷贝已恢复。

多拷贝恢复目前要求分别提供 R1 和 R2 文件；将同一个文件重复作为双端输入会被拒绝，避免制造虚假的配对证据。

图延伸使用 reads 中实际出现的序列上下文：长上下文未被覆盖时，退回有观测支持的较短上下文。参考末端若也出现在其他参考内部，不作为统一停止点。每侧延伸上限为最长参考长度加 `2 × k`；明显超出参考范围的插入仍可能只恢复为片段。ITS2 模式遍历剩余图种子，避免在访问一半种子后漏掉较小的独立组分。只有 reads 覆盖充分且覆盖完整参考范围的候选进入最终分相和竞争模型比较；部分范围模型不能夺走完整模型的配对证据。被更长完整候选严格包含的模型保留为 `UNPHASED`，其他未接纳候选也保留在诊断输出中。边界 reads 的最短精确重叠复用现有 k-mer 长度，仍检查整个重叠区和配对方向。

诊断支持和变异位点的桥接支持均按 reads 的映射端点和方向去重，重复位置不能累加为多份独立分相证据。这是位置去重近似，不是 UMI 分子计数；原始相容片段数仍保留。缺少跨位点连接的等价组合保留为 `UNPHASED`，不利用扩增子对照强行选择模型。

参考与候选坐标采用从 0 开始、右端不包含的区间；`reference_record` 是索引内参考条目的 1-based 序号。输出按不同序列区分，不能统计序列完全相同的基因组拷贝数。

### 初步 WGS 验证

使用 [Denis 等的 WGS 数据](https://doi.org/10.1016/j.cub.2026.04.057)，选取 NC7_3、NC2_12、NC1_14 三个有独立 SymPortal 扩增子重复对照的样本。招募使用独立 Symb-SHIN/GenBank 参考库，扩增子仅用于事后评价，不筛选组装结果。下表比较本轮修复前后，分母为两次扩增子的不同序列并集。

| 样本 | 候选中含完整扩增子序列：修复前 → 后 | reads 支持、来源明确且参考范围完整的匹配：前 → 后 | 共生体流程耗时：前 → 后 |
| --- | --- | --- | --- |
| NC7_3 | 7/19 → 8/19 | 3/19 → 1/19 | 20.55 → 28.56 s |
| NC2_12 | 9/21 → 10/21 | 2/21 → 0/21 | 29.30 → 36.19 s |
| NC1_14 | 10/16 → 10/16 | 1/16 → 1/16 | 35.47 → 37.64 s |

候选序列找回增加不等于可靠单倍型恢复增加。完整竞争模型搜索暴露了此前遗漏的相容组合；诊断支持按映射位置去重也减少了重复 reads 的虚假独立证据。因此严格接纳数降低，不能宣称已解决全部低频拷贝恢复。NC7_3 的 C3ba、C3bd 在 0-based 位点 96 和 218 各有局部相容片段，却没有片段同时覆盖两个位点；NC2_12 的多个完整相容模型仍无法区分。这些序列保留为未解决候选，不通过扩增子对照强行分相。

另用各样本扩增子作为评价专用招募面板，分别招募 154、221、207 个片段，均已存在于独立参考的原始招募池。这项检查未发现面板选择造成的额外遗漏，但不能排除招募器共同的误差/N 处理盲点；评价招募 reads 未参与组装。

NC1_14 的 2 nt 候选是 GC/CG 重复扩增，有等价插入边界。4 条跨事件 reads 对应两个不同起点、两个方向；每组的仪器坐标接近，疑似光学重复，不能按 4 个独立模板计算。高质量局部插入证据不证明完整生物学单倍型；候选仍为 `UNPHASED`，扩增子中未检出，仍需独立文库或长读长验证。扩增子未检出也不单独证明候选是假阳性。

宿主模式分别得到 27、17、18 条来源相对明确、参考范围完整且通过 reads 检查的候选，耗时 38.63、17.41、18.16 s；没有配套宿主 ITS 真值，不能报告宿主恢复率。全部流程从相同原始 WGS reads 开始，参数 `-p 1`，不含下载；扩增子一致性不等于所有生物学拷贝的真值恢复率，也不等于细胞丰度。

本轮扩大搜索后总体耗时增加，没有宣称整体提速。相同 NC7_3 共生体招募池的三轮交替对照中，精确重叠加速实现中位耗时 11.69 s，原实现 11.45 s；另一项精确匹配跳过动态规划为 11.28 对 11.35 s，收益不足以证明稳定提速。两项实验输出均逐字节一致，但均未保留。此前覆盖优先分相的独立性能验证为 32.76 → 9.59 s（NC7_3 宿主招募池，三轮中位数、输出逐字节一致），该优化继续保留。

### 测序错误敏感性与分相复核

对同一三个样本做了评价专用的错误容忍审计：精确重叠至少 21 nt 为基线，另检查至少 75 nt 重叠中的单个低质量错配（Q≤12），且不将错配碱基本身计为覆盖。评价时还排除扩增子对照中等长序列的变异位点，避免将已知拷贝差异解释为错误。扩增子只用于这项审计，不进入生产组装或分相。

具有每碱基至少两个相容片段覆盖的对照序列数为 5→6、12→12、11→11；新增仅 NC7_3 的 C3st。至少 100 nt 重叠、最多两处 Q≤12 错配的补充审计没有额外找回。这是共享 reads 的相容覆盖检查，未要求唯一映射、配对方向或独立分相，不能当作单倍型恢复率。无质量限制的一错配匹配会带入大量 Q40 错配；例如 C3ba 的潜在新桥接依赖位点 119 的 Q40 错配，不能据此补出单倍型。因此本轮没有无差别放宽生产精确匹配，也没有新增参数。

修复了同一映射位置的重复片段可重复累计相邻变异位点桥接支持的问题。两个独立诊断位置仍不足以替代两个独立桥接位置；新增回归测试覆盖了“局部诊断充分，但唯一桥接被重复测序”的情况。无充分联合证据的模型继续保持未分相。

精确支持检查现在用共享种子索引提名偏移，再检查完整重叠，保留重复区域的多重位置及末端匹配规则。400 组含短序列、重复、反向互补、N 和边界截断的对照与原穷举算法逐项一致。NC7_3 共生体招募池三轮交替测试中位耗时 11.39→10.36 s（约快 9%），FASTA、证据表、汇总和 GFA 逐字节一致，峰值内存约 147 MiB、无明显增加。此性能实验在桥接去重修复之前隔离比较，避免将接纳规则变化当作提速。

以下为本轮从原始 WGS 重跑的共生体流程结果（`-p 1`，不含下载）：

| 样本 | 完整扩增子序列候选：本轮前→后 | 严格接纳匹配：前→后 | 全流程耗时：前→后 |
| --- | --- | --- | --- |
| NC7_3 | 8/19 → 8/19 | 1 → 1 | 28.56 → 27.57 s |
| NC2_12 | 10/21 → 10/21 | 0 → 0 | 36.19 → 34.94 s |
| NC1_14 | 10/16 → 10/16 | 1 → 1 | 37.64 → 35.48 s |

六个宿主/共生体流程的候选序列均保持一致。桥接去重将 NC7_3 宿主模式的一条来源未分类候选从 `READ_SUPPORTED` 改为 `UNPHASED`；共生体严格匹配数量不变。

本轮未提高可靠低频单倍型找回率；生产错误容忍仍待独立混合真值校准。144 项测试和静态检查通过。上述全流程耗时各为一次测量；稳定提速证据来自单独的三轮交替对照。

### 基于碱基质量的相容证据补救

FASTQ 的原始 Phred+33 质量与双端序列一起保留；缺少质量的 FASTA 继续精确匹配。新增规则只允许至少 75 nt 重叠中的一个 Q≤12 替换，不容忍 indel 或 N，也不改写 reads 或候选序列。错配碱基本身不计覆盖、诊断或桥接；参与区分候选和连接变异位点的匹配碱基要求 Q≥20。相容的精确模型和低质量错配模型同时保留，不能因允许错配就抹掉真实竞争变异。阈值为内部保守规则，未新增用户参数，也不是经过训练的 DADA2/WGS 错误模型。

补救复用原有候选种子索引，在同一次偏移检查中评估精确和容错匹配。质量不同的相同 reads 分开评估；独立诊断和桥接仍按映射位置去重。`quality_rescued_fragment_support` 记录具有容错位置的相容片段原始计数，不是独立模板数或唯一单倍型证据。

NC7_3 的 C3st 从 257/263 bp 覆盖提高到 263/263 bp，6 bp 缺口消失，状态由 `PARTIAL` 变为 `UNPHASED`。最终有 6 个相容补救片段计数，但仅一个独立诊断位置。独立审计复现了生产计数：在 5 个完整竞争模型中，0-based 位点 96–146 和 146–218 各只有一个独立高质量桥接，未达到两个位置的要求。两条关键低质量 reads 同时精确匹配其他候选，因此不能据此强行接纳 C3st。

| 样本 | 含完整扩增子序列的候选 | 严格接纳：质量补救前→后 | 共生体全流程耗时：前→后 |
| --- | --- | --- | --- |
| NC7_3 | 8/19 | 1 → 1 | 27.57 → 27.55 s |
| NC2_12 | 10/21 | 0 → 0 | 34.94 → 34.79 s |
| NC1_14 | 10/16 | 1 → 1 | 35.48 → 35.43 s |

三个样本均无新增“来源明确、参考完整、通过 reads 检查但未匹配扩增子”的接纳候选；这不是实际假阳性率的证明，扩增子未检出不等于生物学不存在。定向合成负对照中，两个不同起点的 Q12 错误等位基因在旧精确匹配下产生一个错误接纳，新规则为零；将真正次要等位基因改为 Q40 支持时仍能接纳。该测试不代替更广泛的混合样校准。

150 项测试及静态检查通过，包括 200 组容错索引与穷举的一致性检查。NC7_3 相同招募池三轮交替中位耗时为 10.37→10.34 s，差异处于测量波动范围，不宣称本轮进一步提速；各版本重复输出稳定。全流程表格为单次测量，不含下载。

方法参考：[Aspat 的 GraftM ITS2 脚本](https://github.com/hde08/Aspat_WesternPacific_Popgen/blob/master/Scripts/Symbionts/GraftM_ITS2.sh)与 [Symb-SHIN](https://github.com/hisatakeishida/Symb-SHIN/blob/main/C_Read-based_alignment.md)提供 WGS marker 招募/分类范例；[DADA2](https://pmc.ncbi.nlm.nih.gov/articles/PMC4927377/)提供质量相关错误建模的思路；[weebill 架构](https://github.com/wwood/weebill/blob/208eec3cba3aae60198b200d84dd2224b1d84ae9/ARCHITECTURE.md)提供分层筛选与共享证据处理的参考。其基因组级稀疏 sketch、ANI 和丰度模型不直接用于短、多拷贝 ITS2 分相。本实现没有引入这些软件作为新依赖。

### 质量似然与分相图（v15）

参考 [Lorikeet 的候选似然计算](https://github.com/rhysnewell/Lorikeet/blob/master/src/pair_hmm/pair_hmm_likelihood_calculation_engine.rs)和 [Floria 的质量加权分相](https://github.com/bluenote-1577/floria)，复用既有候选位置及 EM，不增加命令行参数或依赖。本实现借鉴统计和图连接思路，没有移植完整 PairHMM、聚类或网络流算法。

在候选等长、每个 mate 的唯一比对范围和方向一致时，用 Phred 错误率比较观测碱基在各候选下的相对似然，再进入原有 EM。共享位置的似然项抵消；重叠双端同一位置取较高质量，碱基冲突则不用于似然。不同长度、裁剪、多位置比对或缺失质量保留等权，避免未建模的插缺和对齐长度造成偏差。EM 不参与接纳判定，也不能被解释为细胞丰度。

分相从“每一对相邻变异位点必须有桥接”改为“所有变异位点必须通过可靠桥接形成连通图”。非相邻位点也能连接，但每条边仍要求至少两个不同映射位置，接纳仍要求至少两个独立诊断位置和完整覆盖。边上的证据最多保留两个位置以限制内存；仅覆盖评估的第一遍不再存储 EM 相容矩阵。

三个样本的宿主、共生体共六个原始 WGS reads 流程均完成。候选序列及接纳状态与 v14 一致；五个模型（四个宿主、一个共生体）的拒绝原因由缺少桥接变为竞争路径未解决，仍不能接纳。

C3st 保持 263/263 bp 覆盖、73 个相容片段和一个独立诊断位置。独立审计发现非相邻 96–218 位点有三个独立桥接，但 96–146、146–218 仍各只有一个；146 位点没有达到两位置门槛的连接，因此仍为 `UNPHASED`。均匀先验似然审计中，仅一个相容片段产生非等权权重，C3st 分数由等分证据的 22.00 降为 21.68；该数值不是独立支持数或生产 EM 丰度。质量建模不能增加未测得的分相信息。

### C3st 位点 146 的原始 reads 审计（v16）

这里的 146 是 0-based 坐标（1-based 为 147）。对 NC7_3 的 21,143,328 对原始 WGS reads，以已有 WGS 候选的全部 15-mer 及反向互补作独立扫描，保留任一 mate 命中的双端；扩增子序列没有用于生产招募或组装。2,842 对含种子，其中 2,689 对不在原招募池。进一步用允许插缺的局部比对要求至少 75 nt、95% 一致性并覆盖该位点，得到 72 条 reads，全部已被原流程招募：70 条为 A，两条为 C3st 的 G。该审计标准下没有发现缺失的独立桥接，短种子命中本身不能当作漏招募证据。

两条 G reads 的该碱基均为 Q40，映射范围同为 `[76,227)`，另一端位于 marker 外且序列相同。测序簇坐标分别为同一 lane/tile 的 `(37723,8872)`、`(37731,8886)`，符合近邻重复的特征，但没有 UMI，不能证明模板来源。最终五个完整竞争模型中，两条均只与 C3st 相容，没有被竞争模型排走。一条在位点 168 的 Q12 替换已经由既有容错规则找回。因此当前限制是一个独立映射位置，不能将两条观测当作两份独立证据。
