# HX50 按 SCO 恢复外显子验证

本轮目标已从“得到完整 CDS”改为恢复外显子，并按用户确认的格式交付：每个样本每个 SCO 一条参考坐标序列，缺失和无法消除的冲突填 N。没有用参考序列填补样本缺失。

参考目录：`/home/yasuda2/starsco/geneminer_sco_refs/fasta`（7,006 个 SCO）。12 个既定面板文件逐字节等于该目录对应文件；注释直接使用此目录，固定其中的 `ppect` 记录作为坐标骨架。参考准备仅处理有候选的家族，避免对其余 6,994 个家族重复翻译。

数据为 HX50（Choriaster granulatus）真实 reads，沿用之前的招募和过滤结果，重新执行组装、分类和两后端注释。不是 ART 模拟数据，也没有重跑全库招募或验证全部 7,006 个 SCO。P. pectinifera 是另一物种，所以下面是参考坐标上的恢复代理指标，不能当作 HX50 的真实外显子边界精度或错误合并率。

SCO_AST_006612_OG0011917 分别恢复 1,933/1,998 和 1,916/1,998 个非 N 碱基，但完整参考外显子区段仅 2/15 和 1/15；零散缺口及冲突会影响很多外显子的完整性。

## 本轮修正

1. 新增逐参考残基到样本 CDS 的显式映射，处理 query 缺失、target 插入、跨内含子密码子及负链，避免以区间长度直接乘三造成后续坐标偏移。相互抵消的插入/缺失也不会被误认为一对一对应。
2. 同一 SCO 中合格短片段不再依赖整条基因模型胜出才进入恢复结果。重叠一致碱基保留，冲突位点为 N，顺序无关；多个参考的坐标不会混用。
3. 新片段组装的图边必须在原始 reads 中出现过，避免仅凭 k-mer 重叠产生未观察到的分叉。候选从 5,503 减至 5,450，旧口径编码覆盖无损。真实、有 reads 支持的分叉仍保留。
4. 明确的 reads 反对证据在链搜索前排除，避免坏边占用有限搜索容量。真实面板没有达到该反对阈值的边，因此不把这项控制测试改进冒充实际恢复增益。
5. 单端唯一定位即使另一端未定位，也可支持外显子。使用去除相同坐标重复后的计数与覆盖并集；这不是跨 contig 连接证据。miniprot 的 676 个外显子坐标候选中 220 个有至少两条唯一比对 reads，194 个坐标区段被映射 reads 全覆盖；Exonerate 对应 1,475 / 317 / 306。这些是可能相互重叠的候选数，不能替代 185 个参考外显子的恢复率。
6. 读段定位由扫描所有 15-mer 改为六个不重叠种子，在既定 ≥90 nt、≤5 个替换的搜索模型下仍覆盖候选；与穷举定位对照验证。重复及多重比对仍不宣称唯一。

ppect 图审计记录 104 / 168 条编码重叠冲突边和 2 / 11 条缺乏一对一修剪坐标的边。它们没有通过任意选取较高得分序列被掩盖。参考骨架汇总可以把冲突掩蔽并保留其他外显子，而原有物理链仍保持未解决。

## 性能与校验

同一机器、同样的招募结果、8 个候选任务：

| 阶段 | 上轮 | 本轮 |
|---|---:|---:|
| 组装 | 1.115 s | 1.315 s |
| miniprot 注释 | 18.096 s | 18.405 s |
| exonerate-rs 注释 | 185.394 s | 179.570 s |

这是单次测量。本轮增加了 SCO 汇总和外显子证据审计；Exonerate 约快 3.1%，miniprot 约慢 1.7%，不能宣称所有后端均更快或普遍性能提升。`exonerate-rs` 仍从当前 PATH 按名称调用。

回归测试覆盖真实分叉保留、未观察图边排除、reads 反对边前置、定位与穷举一致、单端证据、插入/缺失坐标、跨剪接密码子、负链、冲突掩蔽、终止密码子不抄参考及 CLI 参数转发。工作区测试、Clippy、release 构建及输出校验均通过；详尽数据见 [机器可读报告](sco-exon-recovery.json)。
